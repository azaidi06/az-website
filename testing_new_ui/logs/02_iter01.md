# Iteration 01 — first cut of the new design system

Files touched: `redesign.css` (new, ~600 lines), `index.qmd` (rewritten),
`_quarto.yml` (new CSS array, lowercased nav, dropped Brutal Design link, cleaned footer).

## Wins
- Hero: large serif "Ali _Zaidi_" with italic clay accent. Mono eyebrow + mono status row with blinking caret. Reads editorial.
- Index rails: hairline-row pattern works — № column, big serif title, italic serif description, mono meta, mono arrow.
- Portfolio: rails pattern carries cleanly. Mono pills as tags.
- Resume: existing structure retypeset; serif h2/h3 + hairline section dividers + mono dates.
- Dark mode: same identity, not auto-inverted Bootstrap. Clay → warm orange shifts gracefully.
- Navbar: mono uppercase brand "AZ", mono lowercase nav links, hairline border.

## Defects to fix in iter02
1. **Blog page is squeezed.** `blog.qmd` has `page-layout: article` + `toc: true`, which constrains content to ~700px and renders a TOC sidebar. Listing rows wrap absurdly. Fix: drop TOC, break out of article column.
2. **About hero eyebrow touches navbar.** `.about-page main.content` has `padding-top: clamp(60px, 9vh, 120px)` but the eyebrow is positioned above that. Need outer padding.
3. **Footer duplicates.** "© 2026 ali zaidi · azaidi06@gmail.com" on the left + my injected "© ali zaidi · 2026" on the right. Drop the right injection — left text is fine.
4. **Section-head columns don't align with row-link columns.** Section-head uses 200px label gutter; row-link uses 80px. They should share the same column rhythm.
5. **Now-block columns don't align either.** Same fix.
6. **Hero eyebrow very top edge.** Add a bit more top padding past the navbar.
7. **Portfolio rows have a faint "boxed" feel.** Inspect — likely Bootstrap card residue. May just be visual perception of the indented layout.
