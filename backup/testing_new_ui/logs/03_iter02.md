# Iteration 02 — alignment, blog page, content depth

## What changed since iter01
- `redesign.css`: section-head uses 80px gutter (was 200px) so columns align with `.row-link`. Now-block same. Eyebrow gets a small top padding so it baseline-aligns with serif heading. Footer right-cell + injected-content rule removed (was duplicating). Defensive `border: none` on portfolio rows to neutralize legacy `styles.css` borders. Blog listing forced out of `article` column with `max-width: none` overrides.
- `blog.qmd`: rewritten with `page-layout: full`, `toc: false`, `type: default` listing (no thumbnails), and a leading section-head matching the index pattern.
- `about.qmd`: rewritten with proper prose (Background, At a glance, How I work). The `<ul>` becomes a 2-col mono key/value grid via CSS.
- `index.qmd`: `<aside>` → `<section>` for the now-block (Quarto was treating aside as a margin-aside).
- Hero now has `max-width: 1200px; margin: 0 auto` so it doesn't bleed past the rail content.

## What I learned the hard way
- Quarto's `_freeze` cache + rendering multiple `.qmd` files in a single command silently leaked **about-hero + blog-listing markup into the rendered `_site/index.html`**. Fix: `rm -rf .quarto _site/index.html` then re-render. After the cleanup, full renders are clean.
- Playwright + IntersectionObserver fade-ins: items below the fold stay at `opacity: 0` in `full_page` screenshots unless you scroll-trigger them and then force-clear inline styles. Patched the helper.
